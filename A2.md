# Assignment 2 - Part 1

## Running Instructions

### Step 1, 2, 3
Create the required base system:
```bash
vagrant box add bento/ubuntu-24.04 --provider virtualbox
```
Run VM
```bash
vagrant up
```
Update VM
```bash
vagrant provision
```
Delete VM
```bash
vagrant destroy -f
```
### Step 4
Create SSH key
```bash
ssh-keygen -t ed25519 -C "name"
```

Print SSH key
```bash
cat ~/.ssh/id_ed25519.pub
```
